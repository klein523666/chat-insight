# Chat Insight v0.1.1

本补丁版本完善报告任务管理与报告分析控制，不改变 QQ、Telegram、LLM 或飞书的既有
集成范围。

## 新增

- 报告任务支持在 WebUI 中编辑名称、启用状态、来源、周期、时区、飞书目标和提示词。
- 每个任务可选择自适应模式：根据本次报告窗口的原始消息、来源分布和关键词调整分析
  重点；也可保存最多 4,000 字的自定义报告控制提示词。
- 报告任务支持确认后删除，并立即取消后续定时任务。

## 删除范围

删除任务会按既有外键级联规则删除该任务的运行记录、历史报告和投递日志，且无法恢复。
消息源、账号、AI 配置和飞书目标不会被删除。

## 验证

已通过 ruff、mypy strict、36 项 pytest、前端 lint/build、2 项前端测试，以及本机
Docker Core 服务健康检查。QQ、Telegram、LLM 与飞书的 v0.1.0 真实闭环验收结论保持
有效；2C4G VPS 性能仍未验证。
